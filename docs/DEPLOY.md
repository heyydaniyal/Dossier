# Deploying the placeholder app (Streamlit Community Cloud, free)

1. Create a GitHub repository (e.g. `dossier`), push this folder (`git push -u origin main`). Add the other three as collaborators.
2. Go to https://share.streamlit.io, sign in with GitHub, **Create app** → pick the repo, branch `main`, main file path `src/app/streamlit_app.py`, Python 3.11.
3. Dependencies come from `requirements.txt` (generated by `uv export --no-dev --no-hashes --format requirements-txt > requirements.txt`; regenerate whenever `uv.lock` changes).
4. Secrets (from P7 on): app settings → Secrets, e.g. `GEMINI_API_KEY = "..."`. Never commit them.
5. Paste the resulting `https://<name>.streamlit.app` URL into PROJECT_STATE.md → Environment → app URL.
Acceptance check: the page shows three PLACEHOLDER alerts and the footer "Contracts FROZEN v1.0.0" (proves the shared package imports on the host).
